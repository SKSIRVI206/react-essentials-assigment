- **React (Vite)** with Component-Based Architecture.
- **State Management & Hooks:** `useState` for interactive triggers, liking, searching, and filtering. `useEffect` with intervals for live API data syncing and cleanups.
- **Styling:** Fully responsive CSS layouts with dynamic background video/image switching.
